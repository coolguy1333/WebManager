Apps are given http:// addresses, but this dashboard is reached over https Each app's PUBLIC_URL starts with http:// (WEBMANAGER_SITE_PUBLIC_SCHEME=http), while visitors arrive over https, for example through Cloudflare Tunnel. Links and sign-in (OAuth) addresses that apps give out are then wrong, and clients that require https can't connect.

To fix it, on the server: set WEBMANAGER_SITE_PUBLIC_SCHEME=https in /etc/webmanager/webmanager.env, run sudo systemctl restart webmanager, then restart each running app (its page shows a Restart needed button).

{% endif %} {% if insecure_cookie_reasons %}
